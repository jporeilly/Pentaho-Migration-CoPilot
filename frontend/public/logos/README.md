# Source-tool logos

Drop official vendor logo files here (internal tool only) and rebuild the UI
(`.\scripts\dev.ps1 ui-build`). The workbench badge picks them up automatically;
without a file it falls back to a neutral lettermark.

Expected filenames:

- `powercenter.png` — Informatica PowerCenter
- `ssis.png` — SQL Server Integration Services
- `talend.png` — Talend
- `datastage.png` — IBM DataStage

PNG with transparent background, ~40px tall, works best.
